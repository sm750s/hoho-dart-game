# 호호가족의 다트 게임 — 브라우저 검증

## 2026-10-11 Open Graph 검증

타입 검사·기본 빌드 통과. 별도 테스트 주소 `https://og-check.example/hoho/`를 SITE_URL로 지정한 빌드에서 OG URL·이미지 URL·canonical의 하위 경로를 확인했다. 주소는 검증 전용 예시이며 실제 서비스 도메인이 아니다. PNG의 실제 헤더 크기 1200×630과 메타 크기 일치, 빌드 산출물에 이미지 포함, 서버 HTML에서 JavaScript 실행 없이 메타 제공, 이미지 MIME image/png·HTTP 200을 확인했다. 생성된 이미지도 직접 열어 제목·부제·다트판 구성을 확인했다.

[검증 스크립트](../artifacts/browser/verify-og.mjs) · [대표 이미지](../public/og-cover.png) · [생성 프롬프트와 도구](OG_IMAGE_PROMPT.md)

## 회오리 중심 정체 수정 후 검증

타입 검사·빌드·테스트 43개 통과. Chrome에서 네 난이도의 실제 SVG 조준점을 각각 20초 게임 시간 동안 25ms 간격으로 측정했다. 중심 반경 24 안의 표본을 각 40~46회 포함했고 정체 없이 계속 이동했다. 측정된 최저 속도는 쉬움 142·보통 256·빠름 397·매우 빠름 524 SVG 단위/초였고, 중심 부근 최저 속도는 각각 386·613·931·1375였다. 이는 특정 시작 위상의 샘플 결과이며 모든 경로의 정확한 최저값을 뜻하지 않는다. 별도 단위 테스트는 5개 위상·각 2분·10ms 간격으로 중심 통과 중 초당 100 이상을 확인했다.

## 화면 분리 전 기록

Chrome headless에서 실제 React 화면을 로드하고 CDP로 핵심 시나리오 13개를 실행했다. 모두 통과했고 미처리 JavaScript 예외가 없었다. 게임 코드·설정은 변경하지 않았다. 전체 완료 기준 충족과 실제 청취 완료를 뜻하지는 않는다.

## 실행 환경과 방법

- `npm run dev`: 샌드박스 안에서 `http://localhost:6173/` 실행 성공, HTTP 200 확인. 이전 `listen EPERM`은 이번에 재현되지 않았다.
- 전용 브라우저 도구는 없었다. 설치된 Chrome은 샌드박스에서 종료 코드 134였으며, 사용자 승인으로 샌드박스 밖에서 실행한 뒤 `127.0.0.1:9223` CDP 연결에 성공했다.
- 프로필: `/private/tmp/dart-browser-check-escalated-20261010`. 사용자 기존 브라우저 프로필·저장 데이터는 변경하지 않았다.
- 실제 페이지 DOM의 버튼 클릭, CDP Space·터치 입력으로 조작했다. 점수·게임 상태를 직접 주입하지 않았다. 정확한 명중 재현을 위해 `requestAnimationFrame` 콜백의 시간을 제어했다. 실시간 프레임 성능·속도 체감 검증은 아니다.
- 보물 경계는 임시 프로필의 별 저장값을 2/3/4/5/7/8로 준비한 뒤 새로고침했다. 행운 재추첨은 난수값을 고정해 확인했다. 저장 차단은 새 문서에서 `localStorage` 접근이 `SecurityError`를 던지도록 설정했다.
- 자동화 작성 중 비행 후 다음 조준까지 시간을 진행해 명중이 어긋난 경우와 행운 후보 순서를 반대로 가정한 경우를 수정했다. 게임 코드 결함은 아니었고 최종 전체 실행이 통과했다.

## 남은 확인

- 실제 휴대폰/태블릿과 실시간 조준 속도·프레임 성능. 320px 결과는 Chrome 에뮬레이션이다.
- 실제 효과음 상승/하강·음량·3발 완료음·음소거/재시작 취소 청취. 이번에는 음소거 UI만 확인했다.
- 네 미션 전체 선택 흐름, 성공한 다음 새 판의 재보상, 빠름/매우 빠름과 모든 키보드 포커스 조합.
- 다양한 결과 축하 조합, 손상된 저장값/용량 초과/삭제 실패의 브라우저 흐름. 해당 로직은 기존 단위 테스트에서 검증됐다.
- 과거 Phase 2 직접 클릭 투척은 현재 타이밍 게임으로 교체되어 현 버전에서 검증 대상이 아니다. 모든 점수 경계의 정밀 검증은 기존 단위 테스트 결과이며 이번 UI 검증은 중심·판 밖·추첨된 행운 영역을 사용했다.
