# 호호가족의 다트 게임 — Phase 6 미션과 가족 놀이 확장 계획

## 목표와 진행 순서

기존 세 발 다트 게임에 목표를 달성하고, 가족과 경쟁하고, 보상을 모으는 재미를 더한다. 제안한 네 가지 아이디어를 **6-1 미션 도전 → 6-2 가족 대결 → 6-3 보물 모으기 → 6-4 행운의 점수** 순서로 구현한다. 각 하위 단계마다 플레이 가능한 결과를 남기며, 요청받은 단계 하나만 개발한다.

현재 6-1~6-4 전체를 구현했다. 사용자 요청으로 남은 6-3·6-4를 함께 진행했다. 핵심 브라우저 자동화는 통과했으며 전체 완료 기준 중 실제 기기·청취 등은 추가 확인이 남아 있다.

## 공통 규칙

- React + TypeScript + Vite, 브라우저 실행과 백엔드 없는 구성을 유지한다.
- 기존 기본 모드를 유지하고 ‘기본 / 미션 / 가족 대결 / 행운’ 모드를 선택하게 한다. 보물은 모드와 별도의 꾸미기 메뉴다. 아직 구현하지 않은 메뉴는 표시하지 않는다.
- 한 판 3발, 한 발 0~100점, 총점 최대 300점, 기본 목표 180점과 네 가지 조준 속도를 유지한다.
- 모드 변경은 판 시작 전 또는 종료 후에만 한다. 조준·비행 중에는 모드와 미션 변경을 막고, 다시 하기는 조준·비행·예약된 소리를 취소한다.
- 미션·행운 보상은 원래 점수와 분리한다. 색상이나 다트 모양도 판정 영역·조준 속도에 영향을 주지 않는다.
- 완료한 판의 원래 점수만 기존 최고 기록에 반영한다. 가족 대결도 개인별 완료한 세 발 점수를 사용하고 두 사람의 합계를 저장하지 않는다.
- 저장은 같은 브라우저와 접속 주소에서만 유지한다. 저장 실패 시 화면 내 상태로 계속 플레이하고 이를 안내한다.

## 6-1. 미션 도전 [구현 완료 · 핵심 브라우저 검증 통과 · 추가 확인 남음]

**목표:** 점수 외에 매 판 달성할 목표를 보여준다.

기본 모드 옆에 미션 모드를 추가하고, 아래 네 미션 중 하나를 판 시작 전에 고른다. 선택한 미션의 이름, 조건, 진행 상황을 표시한다. 중간에 조건을 달성해도 세 발을 모두 던진 뒤 성공과 별을 확정한다.

| 미션 | 성공 조건 | 아이와 할 활동 |
| --- | --- | --- |
| 높은 곳을 노려라 | 세 발 중 한 발 이상 80점 이상 | 중심 근처를 노리는 타이밍 찾기 |
| 모두 판 안으로 | 세 발 모두 10점 이상 | 판 밖으로 벗어나지 않게 조준하기 |
| 180점 도전 | 세 발 합계 180점 이상 | 발별 점수를 더하고 남은 목표 계산하기 |
| 60점을 찾아라 | 세 발 중 한 발 이상 정확히 60점 | 원하는 띠를 의도적으로 노리기 |

- 성공한 새 판마다 별 1개를 지급한다. 실패·중도 다시 하기·종료 후 추가 입력에는 별을 주지 않는다.
- 같은 결과의 재렌더링이나 저장 복원으로 별을 중복 지급하지 않는다. 새 판에서 같은 미션을 다시 성공하면 별을 받을 수 있다.
- 별 총합을 저장하며 새로고침 시 진행 중인 판은 초기화한다. 결과 화면을 복원해 보상을 다시 지급하지 않는다.
- 결과에서 ‘같은 미션 다시 도전’ 또는 다음 판의 미션 선택으로 이동한다.

**완료 기준:** 네 조건의 성공·실패·경계값을 정확히 판단한다. 세 발 종료 전 별 지급이 없으며 성공당 한 번만 지급한다. 실패·재시작·새로고침·저장 차단에서도 게임과 별 상태가 올바르게 동작한다.

## 6-2. 가족 대결 [구현 완료 · 핵심 브라우저 검증 통과 · 추가 확인 남음]

**목표:** 같은 기기에서 두 사람이 번갈아 즐긴다.

- 플레이어 두 명의 이름과 각자의 조준 속도를 판 시작 전에 정한다. 이름을 비우면 ‘플레이어 1’, ‘플레이어 2’를 사용한다.
- 첫 사람이 세 발을 던진 뒤 점수를 보여주고, ‘다음 플레이어’ 버튼으로 두 번째 사람에게 넘긴다. 자동으로 다음 사람의 조준을 시작하지 않는다.
- 현재 플레이어, 각자 남은 횟수, 발별 점수와 최종 점수를 표시한다. 두 사람 모두 마치면 높은 점수가 승리하며 동점은 공동 승리다.
- ‘대결 다시 하기’는 두 사람의 이번 대결 점수를 초기화하고 이름·속도를 유지한다. 미션 별은 가족 대결에서 지급하지 않는다.
- 이름과 진행 중인 대결은 저장하지 않는다. 새로고침하면 기본 모드로 시작하며, 가족 대결을 다시 선택하면 새 설정부터 시작한다.

**아이와 할 활동:** 가족 이름과 응원 문구를 정하고, 서로에게 맞는 속도를 골라보기.

**완료 기준:** 각자 정확히 세 발을 던진다. 차례 사이의 추가 입력이 다음 플레이어의 투척으로 이어지지 않는다. 플레이어별 속도, 승패·동점, 비행 중 대결 재시작과 최고 기록 반영을 확인한다.

## 6-3. 보물 모으기 [구현 완료 · 핵심 브라우저 검증 통과 · 추가 확인 남음]

**목표:** 미션에서 모은 별을 꾸미기 보상으로 연결한다.

| 보물 | 해제 조건 | 적용 범위 |
| --- | --- | --- |
| 기본 숲 테마 | 처음부터 제공 | 기존 초록·갈색 다트판 |
| 바다 테마 | 누적 별 3개 | 파랑·모래색 다트판 |
| 별빛 다트 | 누적 별 5개 | 비행 다트와 명중 표시의 장식 |
| 우주 테마 | 누적 별 8개 | 보라·하늘색 다트판 |

- 별은 누적 성취 수치이며 보물 해제에 소모하지 않는다. 조건을 만족한 보물은 자동 해제되고 사용자가 선택해서 적용한다.
- 현재 별 수, 해제된 보물, 잠긴 보물의 필요 별 수를 보여준다. 꾸미기는 판 시작 전이나 종료 후에만 변경한다.
- 별과 선택한 보물을 저장한다. 해제 여부는 별 수로 계산하고 잘못된 저장 값이나 잠긴 보물 선택은 기본 테마로 복구한다.
- ‘다시 하기’와 ‘최고 기록 삭제’는 별·보물을 유지한다. 별·선택 보물 초기화는 별도 버튼과 화면 내 취소 가능한 확인 절차로 제공한다.

**아이와 할 활동:** 보물 이름과 색을 정하고, 몇 번의 미션 성공이 필요한지 계산하기.

**완료 기준:** 2→3, 4→5, 7→8개 경계에서 정확히 해제된다. 잠긴 보물은 적용되지 않으며, 꾸미기가 점수나 조준 속도를 바꾸지 않는다. 저장 복원·손상·차단과 보물 초기화도 확인한다.

## 6-4. 행운의 점수 [구현 완료 · 핵심 브라우저 검증 통과 · 추가 확인 남음]

**목표:** 특정 점수 영역을 맞히는 새로운 도전을 제공한다.

- 행운 모드에서 새 판마다 10~100점 중 하나를 같은 확률로 뽑고 시작 전에 보여준다. 0점은 후보에서 제외한다.
- 선택된 영역을 강조하고 숫자·안내 문구로도 표시한다. 한 판 중에는 행운 점수가 바뀌지 않는다.
- 정확히 해당 점수를 맞히면 특별 효과와 ‘행운 명중’ 배지를 보여준다. 한 판에 여러 번 맞혀도 결과 배지는 하나만 준다.
- 배지는 이번 판의 결과이며 저장하거나 별로 환산하지 않는다. 원래 점수와 최고 기록은 보너스 없이 계산한다.
- 다시 하기로 새 판을 시작하면 다시 뽑는다. 같은 점수가 연속으로 나올 수도 있다. 미션·가족 대결과의 결합은 이후 확장으로 남긴다.
- 기존 음소거·동작 줄이기 설정을 특별 효과에도 적용한다.

**아이와 할 활동:** 행운 영역을 찾아보고 같은 점수가 다시 나올 수 있는 이유를 이야기하기.

**완료 기준:** 후보 10개만 선택하고 한 판 내 선택을 유지한다. 명중·미명중·반복 명중·새 판 추첨을 확인한다. 배지가 점수·별·최고 기록을 부풀리지 않고 효과가 음소거·동작 줄이기를 따른다.

## 구조와 검증 계획

미션 판정, 별 지급, 대결 차례, 행운 추첨은 화면과 분리한 TypeScript 로직으로 작성하고 조건·경계·재시작·중복 보상을 테스트한다. UI는 기존 조준·다트판·소리·축하 컴포넌트를 재사용한다. 새 파일은 각 단계에서 필요할 때만 추가하며, 기존 최고 기록 저장 키와 별·꾸미기 저장 키를 분리한다.

각 하위 단계에서 `npm test`, `npm run typecheck`, `npm run build`와 브라우저 검증을 수행한다. 모드 변경, 모바일 터치, 키보드 포커스, 비행 중 재시작, 저장 실패를 함께 확인한다. 실제로 확인하지 못한 항목은 검증 대기로 기록한다.

### 6-1 구현 메모

기본 모드를 기본값으로 유지한다. 첫 가로 위치 확정 전과 종료 후에 모드·미션을 변경할 수 있고, 변경 시 새 판을 시작한다. 진행 중 변경은 막는다. 별은 `family-dart-mission-stars-v1`에 저장하며 현재 판·결과·보상 처리 표시는 복원하지 않는다. 동일 판에는 한 번만 지급하고 새 판의 성공은 다시 보상한다. 최고 기록은 미션과 무관하게 원래 총점만 저장한다.

### 6-2 구현 메모

`src/family.ts`에서 설정·진행·차례 대기·종료를 관리하고 `FamilyPanel.tsx`에서 두 사람의 점수와 차례를 표시한다. 기본 속도는 첫 사람 쉬움, 두 번째 사람 보통이며 이름은 최대 20자다. 설정과 차례 대기 중에는 조준 이동과 투척을 차단한다. 다음 사람은 버튼으로 시작하며 이전 효과음을 취소한다. 대결 다시 하기는 비행을 취소하고 설정 화면으로 돌아가 이름·속도를 다시 확인할 수 있다. 이름과 진행 상황은 저장하지 않는다. 미션 별은 그대로 유지하고, 최고 기록에는 각자 완료한 3발 점수만 반영한다.

### 6-3·6-4 구현 메모

보물 규칙은 `src/treasures.ts`, 화면은 `TreasurePanel.tsx`, 행운 추첨·명중은 `src/luck.ts`로 분리했다. 테마와 다트 장식을 함께 선택하며 별빛 다트를 다시 누르면 기본 다트로 돌아간다. 해제 여부는 별 수에서 계산하고 선택은 `family-dart-cosmetics-v1`에 저장한다. 잘못되거나 잠긴 선택은 기본값으로 복원한다. 초기화 확인 중 조준·투척을 차단하고 취소하면 상태를 유지한다. 확인하면 새 판을 시작하며 최고 기록은 보존한다. 저장 실패 시 화면 내 초기화는 유지하되 저장된 항목이 다시 나타날 수 있음을 안내한다.

행운 모드 진입과 다시 하기에서 새 점수를 뽑으며 조준·투척·꾸미기 선택으로는 바뀌지 않는다. 명중은 발별 기록으로 판정해 반복 명중에도 배지는 하나이며 새 판에는 사라진다. 영역 강조는 `SCORE_ZONES` 반지름을 공유한다. 특별 효과는 시각적 반짝임과 결과 축하이며 별도 소리는 추가하지 않았다. 동작 줄이기는 애니메이션을 생략하고 기존 효과음은 음소거 설정을 따른다.

개발 서버 실행은 작업 환경에서 `127.0.0.1:6173` 바인딩이 `EPERM`으로 차단됐다. React 정적 렌더링은 확인했으며 당시 실제 조작은 미확인이었다. 2026-10-10 재검증에서는 서버 실행과 Chrome CDP 연결에 성공했고 핵심 조작·저장·모바일 에뮬레이션을 통과했다. 실제 청취는 남아 있다.

### 2026-10-10 화면 분리 전 브라우저 재검증

Chrome headless/CDP 핵심 시나리오 13개와 미처리 예외 없음 확인을 통과했다. 사용자 승인 후 별도 임시 프로필을 사용했다. 정확한 조준을 위해 애니메이션 프레임 시간을 제어했으며 게임 상태·점수 함수를 직접 변경하지 않았다. 상세 방법·증거·미확인 항목은 [브라우저 검증 보고서](BROWSER_VERIFICATION.md)를 따른다. 당시 게임 코드와 설정 변경이 없어 기존 단위 테스트·빌드는 반복하지 않았다.

### 2026-10-10 홈·게임·결과 화면 분리

후속 사용자 확인: 실제 모바일 효과음 재생 정상. 처음 무음은 소리를 꺼둔 상태였으며 오디오 코드 변경은 필요하지 않았다. 기기/브라우저 및 세부 음색·취소 청취는 미확인이다.

홈에서 모드·미션·가족 이름/개별 속도를 설정하고 ‘게임 시작’으로 시작한다. 첫 사람 종료는 명시적 차례 대기이며 두 번째 사람 종료는 두 사람 결과 요약으로 전환한다. ‘다시 하기’는 같은 설정으로 바로 시작하고 ‘홈으로’는 진행 중 비행·소리를 취소하고 설정으로 돌아간다. 이전 대결 재시작의 설정 복귀 동작은 사용자 요청으로 대체했다. 꾸미기/별 초기화는 홈에서만 제공하고 초기화 후 시작을 기다린다. 행운은 시작/다시 하기 때만 추첨한다. 홈/결과에서 투척을 차단하고 결과 전환·홈 이동 자체는 별을 추가 지급하지 않는다.

타입 검사·빌드·기존 테스트 39개 및 Chrome 새 화면 전환 시나리오 8개 통과. 미션 재시작 후 새 판 별 지급·결과 중복 방지, 가족 차례·같은 설정 재시작, 행운 배지/점수 분리·재추첨, 320px 터치·세 화면 배치를 확인했다. 실제 기기·청취는 미확인이다. [브라우저 검증 보고서](BROWSER_VERIFICATION.md) 참고.

### 2026-10-10 결과 PNG 카드 저장

결과 화면에서 저장하는 PNG 카드에 미션 성공/실패·이번 판 별 +1/+0, 행운 점수/배지, 가족 이름·개별 난이도·각자 발별/총점·승패를 반영한다. 카드 저장은 별·점수·기록을 변경하지 않는다. 테마 색도 반영한다. 외부 API·공유 기능은 추가하지 않고 다운로드와 미리보기/길게 눌러 저장 안내를 제공한다.

타입 검사·빌드·기존 테스트 39개 및 Chrome 저장 시나리오 5개 통과. 반복 저장 중 별 중복 지급 없음·행운 30점과 배지 분리·두 사람 긴 이름 카드·실패 후 재시도·실제 PNG 다운로드 확인. 생성된 네 카드도 직접 확인했다. 실제 모바일 다운로드/길게 눌러 저장은 추가 확인이 필요하다.
