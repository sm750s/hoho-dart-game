# 호호가족의 다트 게임

‘호호가족의 다트 게임’은 아이와 보호자가 한 단계씩 만드는 React + TypeScript 게임입니다.
브라우저 탭의 파비콘은 가족과 다트판이 그려진 제공 이미지이며 `public/favicon_dart.png`에서 교체할 수 있습니다.
현재 Phase 6: 타이밍에 맞춰 조준점을 멈추고 세 발을 던지는 다트 게임입니다.

- Phase 1~5: 구현 완료, 핵심 브라우저 자동화 통과, 추가 확인 남음.
- Phase 6-1: 미션 도전 구현 완료, 핵심 브라우저 자동화 통과, 추가 확인 남음. 가족 대결도 구현했습니다.
- Phase 6-2: 가족 대결 구현 완료, 핵심 브라우저 자동화 통과, 추가 확인 남음.
- Phase 6-3·6-4: 보물 모으기·행운의 점수 구현 완료, 핵심 브라우저 자동화 통과, 추가 확인 남음.
- 최고 기록 저장·삭제, 결과별 축하 효과, 터치 조작을 구현했습니다.
- 추가 요청으로 투척·완료 효과음과 소리 켜기·끄기를 먼저 구현했습니다. 실제 청취는 검증 대기입니다.
- 상세 검증 결과와 남은 항목은 [기획서의 진행 기록](docs/DART_GAME_PLAN.md#7-진행-기록)에 기록합니다.

## 실행

공개 서비스: [호호가족의 다트 게임](https://hoho-dart-game.vercel.app/)

배포 관리: [Vercel 프로젝트](https://vercel.com/sm750s/hoho-dart-game) · 소스: [GitHub 저장소](https://github.com/sm750s/hoho-dart-game) (`main`)

2026-10-11 사용자 확인으로 Vercel 배포 완료를 기록했습니다. 공개 빌드의 `SITE_URL`은 `https://hoho-dart-game.vercel.app/`을 사용합니다.

Node.js 22.12 이상이 필요합니다. 프로젝트 폴더에서 실행하세요.

```sh
npm install
npm run dev
```

터미널에 표시된 주소(기본 `http://localhost:6173`)를 브라우저로 여세요.
개발 서버와 빌드 미리보기는 `0.0.0.0`에서 수신합니다.
같은 Wi-Fi의 다른 기기에서는 터미널의 Network 주소(`http://이 컴퓨터의 IP:6173`)로 접속하세요.
빌드 미리보기는 터미널에 표시된 포트를 사용하세요.
종료하려면 터미널에서 `Ctrl+C`를 누릅니다.
HTML 파일을 직접 여는 대신 개발 서버 주소로 접속합니다.
게임용 백엔드는 필요하지 않습니다.

## GitHub 업로드 준비

`.gitignore`는 의존성·빌드 결과·로컬 환경 변수·Vercel 설정·로컬 Codex 설정·브라우저 검증의 중복 다운로드를 제외합니다. `.env.example`, `package-lock.json`, `public/`의 이미지와 파비콘, 검증 스크립트·보고서·스크린샷은 저장소에 포함합니다.

Vercel에서 빌드할 때 환경 변수 `SITE_URL`에 실제 공개 서비스 주소를 지정하세요. 환경 변수 파일은 GitHub에 올리지 않습니다.

## 링크 공유 미리보기

Open Graph와 대형 공유 카드 메타를 HTML에 넣었습니다. 제목·설명·한국어·대표 이미지가 JavaScript 실행 없이 전달됩니다. 대표 이미지는 [public/og-cover.png](public/og-cover.png)의 1200×630 PNG입니다.

공개 배포 시 `SITE_URL`에 실제 서비스 주소를 지정하고 빌드하세요. 아래 주소는 예시이며 실제 공개 주소로 바꿔야 합니다.

```sh
SITE_URL=https://game.example.com/ npm run build
```

또는 `.env.example`을 참고해 `.env.local`에 `SITE_URL`을 설정하세요. 하위 경로로 배포하면 그 경로도 포함합니다. 설정값은 OG URL·이미지 URL·canonical에 반영됩니다. 미설정 개발 서버는 LAN 주소(없으면 localhost)를 사용하며, 미설정 빌드는 경고와 함께 localhost 주소를 사용합니다.

현재 Wi-Fi 내부 주소는 외부 공유 서비스가 접근할 수 없으므로 카카오톡 등에서의 실제 미리보기는 공개 배포 후 확인해야 합니다. 대표 이미지는 내장 imagegen으로 생성했습니다. [최종 생성 프롬프트](docs/OG_IMAGE_PROMPT.md)

## 홈 → 게임 → 결과

1. 홈에서 모드와 난이도를 고릅니다. 미션은 목표를, 가족 대결은 두 사람의 이름과 속도를 설정합니다.
2. ‘게임 시작’을 누르면 다트판과 조작 버튼이 있는 게임 화면으로 이동합니다.
3. 세 발이 끝나면 결과 화면에서 총점·발별 점수·미션 별·행운 배지를 확인합니다. 가족은 첫 사람 종료 후 ‘다음 플레이어’로 넘기고 두 사람 모두 끝나면 결과를 요약합니다.
4. ‘다시 하기’는 같은 모드와 설정으로 바로 새 게임을 시작합니다. ‘홈으로’는 모드 선택 화면으로 돌아갑니다.

홈의 보물 상자를 펼쳐 꾸밀 수 있습니다. 게임 중 홈 이동·다시 하기는 비행과 소리를 취소하며 최고 기록·별·꾸미기는 유지합니다. 새로고침하면 홈으로 돌아갑니다.

게임 모드 → 조준 방식 → 난이도 순서로 설명이 있는 카드를 눌러 선택합니다. 기본 난이도는 단독·가족 두 사람 모두 보통입니다. 진한 색 카드가 현재 선택이며 가족 대결의 두 사람 난이도도 각각 카드로 고릅니다. 키보드 Tab으로 이동하고 Space/Enter로 선택할 수 있습니다.

## 아이와 색상 바꾸기

`src/style.css`의 `--board-green`, `--board-brown` 값을 좋아하는 색으로 바꾸고 저장하세요.
개발 서버가 실행 중이면 변경 사항이 화면에 반영됩니다.

## 세 발로 도전하기

홈의 ‘조준 방식’에서 **가로·세로 조준** 또는 **회오리 조준**을 선택하세요. 회오리에서는 조준점이 반지름과 회전 속도를 바꾸며 과녁 안팎으로 움직입니다. ‘지금 위치에 던지기’ 또는 Space를 **한 번** 누르면 그 위치로 던집니다. 다트마다 출발 위치가 달라지고 난이도가 높을수록 움직임이 빨라집니다. 기본·미션·가족·행운 모두 함께 사용할 수 있으며 다시 하기는 선택한 조준 방식을 유지합니다. 결과와 PNG 카드에도 조준 방식을 표시합니다.

아래 두 단계 설명은 기본값인 가로·세로 조준에 해당합니다.

회오리 조준은 중심에서도 멈추거나 느리게 머무르지 않도록 두 회전을 겹친 경로로 개선했습니다. 중심을 빠르게 지나가며 회전 속도와 방향이 계속 변합니다. 쉬움부터 매우 빠름까지 이 경로를 사용합니다.

‘가로 위치 정하기’를 눌러 좌우 조준점을 멈추고, ‘세로 위치 정하고 던지기’를 눌러
위아래 위치를 확정하세요. 버튼 대신 Space 키도 사용할 수 있습니다.
버튼이나 선택 항목에 포커스가 있으면 Space는 해당 요소의 기본 동작을 수행합니다.
다트판 직접 클릭은 타이밍 조작으로 변경했습니다.
가로·세로 조준은 쉬움 150, 보통 270, 빠름 420, 매우 빠름 600 SVG 좌표 단위/초로 움직입니다.
회오리 조준은 쉬움 대비 보통 1.3배, 빠름 1.8배, 매우 빠름 2.8배로 속도를 완만하게 높입니다. 새 매우 빠름은 기존 회오리 빠름 수준입니다.
난이도는 홈에서 선택하며 다시 하기 후에도 선택값을 유지합니다.

점수 영역은 10개입니다. 가장 작은 중심점 100점부터 바깥으로
90·80·70·60·50·40·30·20·10점이며, 테두리와 판 밖은 0점입니다.
중심점 반지름은 6, 나머지 띠 폭은 약 18~21 SVG 좌표 단위로 좁혔습니다. 경계는 안쪽 점수로 계산합니다.
약 0.45초 비행 후 점수를 반영하고 명중 효과를 표시합니다. 비행 중 추가 입력은 무시됩니다.
새로운 명중 표시는 노란색으로 강조됩니다. 한 판에 세 발이며 판 밖 명중도 한 발을
소모합니다. 남은 횟수와 발별 점수가 표시되고 세 번째 발 이후에는 결과가 나타납니다.
종료 후 클릭은 점수에 반영되지 않습니다. ‘다시 하기’를 누르면 점수, 횟수와 모든 표시가
지워지고 가로 조준부터 새 판이 시작됩니다. 조준·비행 중 다시 하기도 지원하며
이전 비행은 점수에 반영되지 않습니다. 새로고침도 판을 초기화합니다.

## 미션 도전

‘미션 도전’을 선택하고 판 시작 전에 네 미션 중 하나를 고르세요.

- 높은 곳을 노려라: 한 발 이상 80점 이상.
- 모두 판 안으로: 세 발 모두 10점 이상.
- 180점 도전: 합계 180점 이상.
- 60점을 찾아라: 한 발 이상 정확히 60점.

진행 상황을 보며 세 발을 모두 마치면 성공 여부를 확인하고, 성공한 판마다 별 1개를 받습니다.
조건을 일찍 달성해도 세 발 종료 전에는 별을 주지 않습니다. 실패와 중도 재시작에도 별이 늘지 않습니다.
같은 미션에 다시 성공하면 새 별을 받을 수 있습니다. 모드·미션을 바꾸려면 ‘홈으로’를 누르세요.

별은 점수와 별개로 저장됩니다. 새로고침하면 기본 모드가 선택된 홈으로 돌아가고 별 총합만 복원합니다.
최고 기록 삭제와 다시 하기는 별을 지우지 않습니다. 저장 실패 시 별을 화면 안에 유지하고 안내합니다.
보물 상자에서 해제된 꾸미기를 선택할 수 있습니다.

## 가족 대결

‘가족 대결’에서 두 사람의 이름과 각자 사용할 속도를 고르고 ‘게임 시작’을 누르세요.
이름을 비우면 플레이어 1·2로 표시됩니다. 첫 사람이 세 발을 마친 뒤 ‘다음 플레이어’를 누르면
두 번째 사람의 조준이 시작됩니다. 각자 세 발을 마치면 승자를 표시하며 동점은 공동 승리입니다.

‘다시 하기’는 같은 이름·속도로 새 대결을 바로 시작합니다. 설정을 바꾸려면 ‘홈으로’를 누르세요.
이름과 대결은 저장하지 않으며 새로고침하면 기본 모드가 선택된 홈으로 돌아갑니다. 가족 대결에서 별은 지급하지 않고,
최고 기록은 두 사람의 합계가 아닌 개인별 완료한 세 발 점수만 반영합니다.
브라우저에서 차례 대기 중 Space 입력 차단, 개인별 속도, 비행 중 재시작과 모바일 화면을 확인하세요.

## 아이와 목표 정하기

기본 목표는 180점, 만점은 300점입니다. `src/game.ts`의 `TARGET_SCORE`를
0~300 사이의 목표로 바꾸거나 `getResultMessage`의 응원 문구를 함께 작성하세요.

## 최고 기록과 축하 효과

세 발을 모두 마친 판의 최고 점수를 저장합니다. 같은 브라우저와 접속 주소에서
새로고침하거나 다시 열어도 유지됩니다. 난이도별 구분 없이 최고 기록 하나를 관리합니다.
‘다시 하기’는 현재 판만 초기화하고, ‘최고 기록 삭제’는 현재 점수를 유지하며 저장 기록만 지웁니다.
종료 후 기록을 삭제해도 같은 판을 다시 저장하지 않으며 다음 완료한 판부터 새 기록을 쌓습니다.
저장 기능을 사용할 수 없으면 화면 안에서 기록을 유지하고 안내를 표시합니다.
삭제 실패 시 브라우저에 저장된 기록이 다시 나타날 수 있음을 알립니다.

만점·새 기록·목표 달성에는 축하 문구와 색종이 효과를, 나머지 결과에는 응원 문구를 표시합니다.
기기의 ‘동작 줄이기’ 설정을 켜면 색종이와 명중 효과 애니메이션을 생략합니다.
작은 화면에 맞춰 버튼을 배치하며 클릭·터치는 같은 입력 경로로 처리해 중복 투척을 피합니다.

## 효과음

사용자가 실제 모바일에서도 효과음 재생을 확인했습니다. 소리가 안 들리면 게임의 효과음 설정과 기기 음량을 확인하세요.

다트를 던지면 0~50점은 내려가는 음, 60~100점은 올라가는 음이 납니다.
높은 점수일수록 더 높은 음으로 끝나며, 세 번째 발 뒤에는 “따단!” 느낌의 완료음이 이어집니다.
효과음은 기본으로 켜져 있으며 ‘효과음 켜짐/꺼짐’ 버튼으로 전환합니다.
소리를 끄거나 다시 하기를 누르면 재생 중·예약된 효과음도 취소합니다.
첫 투척 조작부터 재생하며, 외부 음원이나 오디오 권한 요청 없이 Web Audio로 생성합니다.
오디오를 사용할 수 없어도 게임은 계속됩니다.

## 결과 이미지 저장

결과 화면에서 ‘결과 이미지 저장’을 누르면 점수·발별 기록·미션 결과·행운 배지 또는 두 사람의 대결 결과를 한 장의 PNG 카드로 저장합니다. 카드에는 최고 기록과 모은 별도 담깁니다. 저장한 이미지를 카카오톡 등에서 첨부해 친구에게 보내세요.

자동 저장이 안 되면 화면에 나타나는 ‘PNG 이미지 저장’ 링크를 누르거나 미리보기 이미지를 길게 눌러 저장하세요. 브라우저 안에서 이미지를 만들며 별도 서버·회원가입·HTTPS 배포 없이 현재 Wi-Fi 주소에서도 사용할 수 있습니다. 이미지 저장은 점수·별·최고 기록을 변경하지 않습니다.

Chrome의 320px 모바일 에뮬레이션에서 네 모드 카드 생성·실제 PNG 다운로드·반복 저장·실패 후 재시도를 확인했습니다. 실제 휴대폰의 다운로드/길게 눌러 저장 동작은 추가 확인이 필요합니다. [기본 카드 예시](artifacts/browser/card-basic.png) · [가족 카드 예시](artifacts/browser/card-family.png)

## 검증과 빌드

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성되며 정적 호스팅으로 제공할 수 있습니다.
미리보기 주소를 열어 새로고침과 다트판 표시를 확인하세요.
`npm test`는 Node 내장 테스트로 점수 경계, 좌표 변환, 3발 제한, 종료 후 입력 차단,
다시 하기와 결과 문구, 두 단계 조준·속도·비행 상태 전환을 확인합니다.
가족 대결 테스트는 설정·차례·개인별 3발·승패·동점·재시작을 확인합니다. 회오리 경로·범위·입력 잠금·프레임 독립성·중심 정체 방지 테스트를 포함한 전체 테스트는 43개입니다.
미션 테스트는 네 조건의 경계, 완료 전 지급 금지, 중복 지급 방지, 새 판의 재보상을 확인합니다.
기록 테스트는 저장·복원, 손상된 값, 접근 차단·용량 초과·삭제 실패를 확인합니다.
오디오 제어 테스트는 완료음 예약 순서, 취소, 재생 차단 처리를 확인하며 실제 청취를 대신하지 않습니다.
브라우저에서는 버튼·Space로 두 단계 조준을 해보고 쉬움·보통·빠름·매우 빠름을 비교하세요.
비행 중 연속 입력, Space 길게 누르기, 종료 후 조작이 추가 투척을 만들지 않는지 확인하세요.
진행 중과 종료 후에 다시 하기를 눌러 점수·명중 표시·기록·남은 횟수가 초기화되는지도 확인하세요.
효과음은 실제 브라우저에서 투척음, 세 번째 발의 완료음, 종료 후 클릭 시 무음,
소리 끄기·켜기와 완료음 도중 다시 하기를 확인하세요.

추가 브라우저 확인: 320px 화면과 터치 기기에서 조준·다시 하기·음소거를 조작하세요.
한 판 종료 후 새로고침해 최고 기록이 유지되는지, 다시 하기는 기록을 보존하는지,
기록 삭제는 현재 판을 보존하는지 확인하세요. 저장 차단 환경에서도 게임이 동작해야 합니다.
결과별 축하 효과와 동작 줄이기 설정도 확인하세요.

## 보물 모으기와 행운의 점수

미션 별 3개로 바다 테마, 5개로 별빛 다트, 8개로 우주 테마를 해제합니다. 별은 소모하지 않습니다. 홈의 보물 상자에서 선택하세요. 테마와 다트 장식은 함께 적용하며 별빛 다트를 다시 누르면 기본 다트로 돌아갑니다. 별과 선택은 저장되고 점수·조준 속도는 그대로입니다.

‘별·보물 초기화’는 확인과 취소 버튼을 제공합니다. 확인하면 별과 꾸미기를 지우고 홈에서 시작을 기다리며 최고 기록은 보존합니다. 저장 실패는 안내합니다.

‘행운의 점수’는 새 판마다 10~100점 중 한 영역을 같은 확률로 뽑아 강조합니다. 정확히 맞히면 반짝임과 행운 명중 배지를 표시합니다. 반복 명중해도 배지는 하나이며 점수·별 보너스는 없습니다. 배지는 이번 판에만 남습니다. 다시 하면 재추첨하며 같은 점수가 나올 수도 있습니다. 동작 줄이기는 반짝임 애니메이션을 생략하고 기존 효과음은 음소거 설정을 따릅니다.

브라우저에서 해제 경계·선택 저장·초기화 취소·행운 영역·판 중 점수 고정·모바일 조작을 확인하세요.
